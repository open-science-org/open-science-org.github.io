# open-science-org.github.io

Source of www.oso.network.

Since the 2026 restart, `index.html` is a single hand-written page with inline styles and no build step. The older pages (`teams.html`, `projects.html`, `faqs.html` and others), the `*.mustache` templates and the CI build are from 2017–2019 and are no longer linked from the home page. Do not run the old build scripts: they would overwrite `index.html`.
