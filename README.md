# open-science-org.github.io

Source of www.oso.network.

Since the 2026 restart, `index.html` is a single hand-written page with inline styles and no build step.

The previous website is kept for history: `2017.html` is the old home page (with a banner linking back to the current site), and the older pages (`teams.html`, `projects.html`, `faqs.html` and others) link to it as their home. The new home page links to `2017.html`.

The `*.mustache` templates and the CI build are from 2017–2019 and are retired. Do not run the old build scripts: they would overwrite `index.html` and would not regenerate `2017.html`.
